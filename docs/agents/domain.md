# Domain Docs

This is a single-context repository.

## Source documents

- Read the root `CONTEXT.md` before exploring domain code.
- Read relevant decisions in root `docs/adr/` when they exist.
- Use the vocabulary defined in `CONTEXT.md` for tickets, tests, and design
  documents.

## Layout

The root `CONTEXT.md` is the shared domain glossary and boundary document.
Architecture decisions belong in `docs/adr/` and should be added only when a
decision needs durable explanation.
