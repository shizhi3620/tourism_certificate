# Tourism MVP 产品需求文档

**编号**：PRD-001  
**版本**：v0.1.2  
**状态**：MVP 开发基线  
**目标地区**：四川省  
**目标考试**：2026 年全国导游资格考试（全国大纲四科笔试；四川现场考试英语面试）  
**日期**：2026-09-14

## 1. 产品定位

Tourism 是面向全国导游资格考试个人考生的备考工具。首期服务四川考生，
以 2026 年全国笔试大纲和四川现场考试大纲为内容基线，并通过“共享能力
+省份数据包”扩展到全国。

全国笔试不因现场考试语种而改变，始终按照全国考试大纲的四个科目组织；
英语只适用于四川现场考试的面试训练部分。

产品不复制参考项目的题库内容，只借鉴其刷题、模考、错题和训练闭环思路。

## 2. 用户与目标

### 目标用户

准备参加 2026 年四川导游资格证考试、并选择英语现场考试的个人考生，包括零基础和已有
基础的考生。培训机构、教师后台、其他语种暂不属于 MVP。

### 产品目标

1. 让考生按官方大纲组织笔试学习。
2. 形成“章节练习—历年真题—错题复习—整卷模考”的闭环。
3. 通过基础统计帮助考生识别进度和薄弱章节。
4. 以低成本方式运行在个人 NAS，并支持公网访问。
5. 为四川现场考试和全国省份扩展预留数据模型。

## 3. 范围与优先级

### P0：全国笔试闭环

- 考纲目录：展示科目、章节和知识范围。
- 四个笔试科目：按全国大纲组织，不按现场考试语种区分笔试题库。
- 学习进度：记录章节学习状态和练习进度。
- 章节练习：按章节答题、提交、查看答案和解析。
- 历年真题：作为独立题源进行练习和统计。
- 错题本：自动收录答错题，并支持再次练习。
- 整卷模考：按题量、分值和时间配置，支持计时、交卷和成绩。
- 基础统计：学习量、正确率、章节表现、真题表现和模考成绩。

### P1：四川现场考试训练

依据四川 2026 年现场考试大纲，优先建设：

- 四川景点导游词；
- 中英文对照和中文释义；
- 英文导游词练习；
- 现场考试问答；
- 评分维度和自评清单；
- 录音训练。

发音分析、AI 点评、自动评分和长期录音存储不属于 P0，需另行确认。

### 非目标

MVP 不提供培训机构后台、付费会员、题库售卖、考试结果承诺或未经审核的
AI 内容作为正式答案。

## 4. 内容与题库

### 内容基线

- 全国笔试：`附件2：《2026年全国导游资格考试笔试大纲》.pdf`
- 四川现场：`附件3：《四川省2026年全国导游资格考试现场考试大纲》.pdf`

### 题源政策

题目分为：

1. 官方公开材料；
2. 自行编写或取得授权的内容；
3. 考生回忆题。

历年真题必须与模拟题分开管理。回忆题标注“非官方回忆/待审核”，不得
伪装成官方原题。只允许状态为“已审核”的题目进入默认练习和模考。

### 题目元数据

每题至少保存题目 ID、科目、章节、知识点、题型、选项、答案、解析、题源、
考试年份、适用地区、审核状态、来源说明、创建时间和更新时间。

## 5. 语言与体验

- 移动端优先，兼容桌面浏览器。
- 产品界面、考纲说明和笔试解析以中文为主；笔试按全国大纲的四个科目组织。
- 现场考试训练使用英文，并提供中文释义和错误说明。
- P0 优先保证答题、进度恢复、错题复习和模考流程清晰可靠。

## 6. 数据与隐私

- 允许游客使用公开题目和基础练习。
- MVP 优先使用浏览器本地保存进度、错题和统计。
- 不强制账号和跨设备同步；后续可增加账号并支持本地数据迁移。
- P0 不需要录音；未来录音默认不长期保存，保存前需取得明确同意并提供删除。
- 日志不得记录凭证、完整录音或不必要的个人敏感信息。

## 7. 部署与非功能需求

- 后端运行在家用 NAS。
- 通过 Cloudflare Tunnel 对外访问。
- 优先采用 Cloudflare 免费方案、本地存储和免费软件。
- 不依赖付费云服务器、付费数据库或付费 AI 服务。
- NAS 关机或家庭网络中断导致服务不可用，是 MVP 可接受限制。

公网访问前必须具备认证、基础限流、NAS 服务隔离、数据备份、日志脱敏、
依赖更新和可恢复部署配置。Cloudflare Tunnel 不替代应用层安全控制。

## 8. 打赏入口

可通过 `DONATION_URL` 配置自愿支持入口。打赏：

- 不解锁题库；
- 不提供会员或优先服务；
- 不影响未打赏用户使用核心功能；
- 不承诺考试结果；
- 不应强制打断答题和成绩流程。

## 9. 全国化架构方向

全国笔试能力、题型、错题和模考共用一套实现；省份通过数据包提供现场考试
大纲、景点、导游词、问答和评分标准。四川是第一个省份数据包，新增省份
不得复制整套业务代码。

## 10. P0 验收标准

1. 可查看已录入的 2026 全国笔试科目和章节。
2. 可完成章节练习并查看结果和解析。
3. 历年真题与模拟题在界面和统计中可区分。
4. 真题展示年份、地区、科目、来源和审核状态。
5. 答错题自动进入错题本并可再次练习。
6. 可完成整卷模考并记录计时、答案和成绩。
7. 可查看与答题记录一致的基础统计。
8. 待审核题目不进入默认练习和模考。
9. 服务可在 NAS 启动并通过 Cloudflare Tunnel 访问。
10. 打赏入口可配置启用或关闭且不影响核心流程。
11. 题库和学习数据具备备份恢复说明。

## 11. MVP 默认决策与后续扩展

为避免细节阻塞 MVP 开发，以下决策作为 v0.1.1 的实施默认值。它们不是对
官方规则的替代；考试规则和题目内容以附件大纲及后续官方公告为准。

| 事项 | MVP 默认决策 |
| --- | --- |
| 笔试题型、题量、分值、时长 | 从附件 2 和正式考试公告建立版本化配置，不在代码中硬编码；配置变更需更新版本 |
| 历年真题范围 | 优先收录可合法使用的公开或授权材料；不设虚假的“完整年份覆盖”承诺，首批数量以审核能力为准 |
| 四川现场内容 | 首批覆盖附件 3 列出的考试要求和景点；按内容审核状态逐步开放 |
| 题库维护 | P0 使用版本化 JSON/CSV 等结构化文件维护，不开发管理后台 |
| 账号与同步 | P0 不强制账号，学习数据保存在浏览器本地；跨设备同步列为后续能力 |
| 录音、发音分析、AI 点评 | 不进入 P0；P1 先支持浏览器临时录音和手动复盘，AI/发音分析另行评估 |
| 打赏方式 | 使用可配置的外部链接或二维码说明；上线前单独检查平台规则和展示合规性 |

如果官方大纲、考试公告或版权授权条件发生变化，应新增 PRD 修订版本，
同步更新内容数据和验收配置。
