# Tourism 需求文档

本目录是 Tourism 产品需求的唯一事实来源。

## 文件与版本规范

- 文件名：`PRD-<编号>-<主题>-v<主版本>.<次版本>.<修订版本>.md`
- `主版本`：产品范围、兼容性或核心目标发生不兼容变化时递增。
- `次版本`：在同一产品阶段增加功能范围时递增。
- `修订版本`：澄清文字、补充验收标准或修正不改变范围的细节时递增。
- 每个版本都必须在文档的“版本记录”中说明变更、原因和影响。
- 当前开发必须以当前基线表中标记为“开发基线”的文档为准。

## 发布规则

1. 先修改需求文档，再修改实现和内容数据。
2. 需求范围变化必须升级版本；实现细节修正不应伪装成需求版本升级。
3. 官方大纲、考试公告或内容授权发生变化时，新增版本并同步更新内容数据版本。
4. 已发布版本保留，不覆盖历史版本。
