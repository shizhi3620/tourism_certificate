# 05 — 实现四川现场考试英文训练首个切片

**What to build:** 让四川英文导游资格证考生按照四川 2026 年现场考试大纲查看首批景点和训练材料，进行中英文对照的英文导游词与现场问答练习，并查看自评维度。

**Blocked by:** 01 — 建立版本化考试内容与大纲目录

**Status:** ready-for-agent

- [ ] 以四川省份数据包承载现场考试要求、景点、导游词、问答和评分维度。
- [ ] 展示中文说明、英文训练内容和中文释义。
- [ ] 支持按景点和问答条目开始、完成和重复练习。
- [ ] 标记内容审核状态，不展示未审核内容为正式训练材料。
- [ ] P1 首个切片使用浏览器临时录音或手动复盘，不默认长期保存录音。
- [ ] 不引入 AI 点评、发音分析或自动评分，除非后续需求版本明确加入。
