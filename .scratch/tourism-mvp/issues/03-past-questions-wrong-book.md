# 03 — 实现历年真题与错题本闭环

**What to build:** 让考生可以单独练习带年份、地区、科目、来源和审核状态标识的历年真题；答错题自动进入错题本，并支持重新练习和状态更新。

**Blocked by:** 02 — 实现章节练习与本地学习进度

**Status:** done

- [x] 在题目列表和练习流程中明确区分历年真题、模拟题和示例题。
- [x] 展示历年真题的年份、适用地区、科目、题源和审核状态。
- [x] 回忆题显示非官方/待审核提示，不进入默认练习或模考。
- [x] 答错题自动进入本地错题本。
- [x] 错题本支持再次作答，并根据最新结果更新状态。
- [x] 统计区分真题表现和其他题源表现。
