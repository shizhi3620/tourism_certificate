# 01 — 建立版本化考试内容与大纲目录

**What to build:** 让维护者可以按 2026 年全国笔试大纲和四川现场考试大纲维护版本化的科目、章节、题目元数据和内容审核状态；让考生只能看到已发布的内容，并明确区分示例、模拟题、历年真题和待审核内容。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 建立可版本化的全国笔试和四川省份数据包结构。
- [x] 记录科目、章节、知识点、题源、年份、地区、审核状态和来源说明。
- [x] 默认练习和模考只返回已审核内容。
- [x] 展示大纲版本和内容版本，官方规则变化时可新增版本而不覆盖历史。
- [x] 用合成内容覆盖内容加载、版本读取和待审核过滤测试。
