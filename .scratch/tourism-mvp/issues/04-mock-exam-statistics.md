# 04 — 实现整卷模考与基础统计

**What to build:** 让考生按照版本化考试配置完成整卷模拟考试，记录答案、用时和成绩，并查看总表现、章节表现、历年真题表现和模考趋势。

**Blocked by:** 02 — 实现章节练习与本地学习进度；03 — 实现历年真题与错题本闭环

**Status:** done

- [x] 按版本化配置生成只包含已审核内容的整卷模考。
- [x] 支持开始、计时、暂存答案、交卷和查看结果。
- [x] 防止重复交卷造成重复成绩记录。
- [x] 保存本地模考结果，重启或刷新后可查看历史结果。
- [x] 展示总正确率、章节表现、真题表现、错题数量和模考成绩。
- [x] 使用合成题目覆盖计时、交卷、恢复和统计一致性测试。
