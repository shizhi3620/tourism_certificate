# 02 — 实现章节练习与本地学习进度

**What to build:** 让考生按照大纲章节进行练习，提交答案后立即看到结果和解析，并在不登录的情况下恢复本地答题记录、章节进度和基础正确率。

**Blocked by:** 01 — 建立版本化考试内容与大纲目录

**Status:** ready-for-agent

- [ ] 从已发布内容中选择章节题目并完成答题流程。
- [ ] 提交后显示正确性、正确答案和解析。
- [ ] 使用浏览器本地存储保存答题次数、正确次数和章节进度。
- [ ] 刷新页面或重新打开服务后可以恢复本地进度。
- [ ] 空内容、错误内容和待审核内容有明确的用户提示。
- [ ] 用外部 HTTP 和浏览器行为测试覆盖主要练习流程。
